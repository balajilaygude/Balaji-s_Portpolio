# 🎨 Personal Portfolio Website

## Overview

This is a modern and responsive **Personal Portfolio Website** built using **React.js** and **Tailwind CSS**.

The portfolio is designed to showcase my skills, projects, experience, and professional profile through a clean and interactive user interface. The application follows a component-based architecture, where each major section of the portfolio is built as a reusable React component.

The project was created to strengthen my frontend development skills and gain hands-on experience with modern React development, reusable components, React Hooks, and responsive UI design using Tailwind CSS.
